# Git and GitHub Application Deployment

## Project Overview
This project demonstrates Git and GitHub source-code management
and application deployment using Docker Compose.

## Technologies Used
- Git
- GitHub
- Docker
- Docker Compose
- Node.js
- Nginx

## Project Files
- Dockerfile: Builds the application image.
- app.js: Node.js application.
- compose.yaml: Defines the application services.
- nginx.conf: Nginx configuration.
- website/index.html: Website page.

## Deployment
The application is deployed locally using Docker Compose.
